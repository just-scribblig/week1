# Week 1 – Financial News Sentiment & Market Data Analysis
### Project Overview

This repository contains my Week 1 work for the AI Engineering program. The goal is to analyze financial news headlines, extract sentiment, correlate it with market indicators, and build a structured workflow using Python, Git, and CI.

### Objectives
- Perform structured Exploratory Data Analysis on financial headlines
- Compute and visualize descriptive statistics
- Prepare market data using yfinance and technical indicator libraries
- Establish a clean Git workflow with feature branches
- Integrate CI workflows (unittests.yml) for automated testing
- Build reproducible Jupyter workflows with modular code
